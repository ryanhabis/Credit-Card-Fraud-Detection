# Credit Card Fraud Detection: A Data-Driven Analytical Approach

## 📌 Overview
This project analyzes credit card fraud patterns using the Kaggle "Credit Card Fraud Detection" dataset (284,807 transactions, 0.17% fraud). Following the CRISP-DM framework, we apply exploratory data analysis, statistical tests, and visualizations to uncover fraud patterns.

## 🎯 Key Findings
- Fraudulent transactions are **€35.46 higher on average** (p < 0.01)
- **V14 and V12** are the strongest fraud predictors (logistic regression)
- Fraud peaks at **11 AM** with moderate activity from **1–2 AM**
- **84.3% recall** but only **9.2% precision** in fraud detection
